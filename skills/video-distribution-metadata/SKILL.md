# Video distribution metadata

Read the finished video or approved edit, its intended audience, and the target platforms. Draft factual titles and summaries that reflect what appears in the video. Derive chapter timestamps from the final export rather than from an earlier timeline.

Check current platform limits and format requirements from official documentation before preparing a platform-specific package. Include requested language variants, accessibility text, credits, and asset attribution where applicable. Verify that metadata does not promise content absent from the video or reveal private source details.

Create files or drafts for review. Upload, schedule, or publish only when the user has authorized that external action. For the Hu Tao project, distinguish the reference work, character model attribution, and original audio as appropriate for the destination.
